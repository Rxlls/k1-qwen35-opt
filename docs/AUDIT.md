## 4. 核对结论

1. **核心结论全部成立**：prefill 翻倍（2B +87.8%、4B +113.2%）、decode 持平或小幅转正、优势随上下文单调收窄——三组数据均有归档原始文件，百分比重算无误，今晚独立复跑再次复现（+84.7%）。归因（量化类型是否在 IME 白名单内）有张量级证据（55 → 1），不依赖性能数字。
2. **必须处理 1 项**：A2 温度判据的自相矛盾。这是我今晚修改造成的，责任在我——已在 DEPLOY §5.5 改为"分窗口表述 + 声明低温侧无归档"，并建议技术文档把该判据限定到具体两次观察。
3. **需要决策 1 项**：A1 的 8.17 / 8.26。差 1.1%，不影响结论，但会让"文档值 ↔ 归档值"对不上；改与不改都要留痕。
4. **证据缺口 5 项**：32K 内存、线程 8、v0.2.3 三组数字有值无档。它们不颠覆结论，但若评审索要原始输出，只能提供本次核对时的口头说明。建议补做：32K RSS 用 `/usr/bin/time -v` 重测一次即可归档（约 3 分钟），线程 8 与 v0.2.3 各重跑一次 bench（约 5 分钟/次）。
5. **未发现的问题**：模型体积、张量数量、部署项数、TTFT、三次独立实验、以及所有派生百分比，逐项核对全部一致，无夸大。
