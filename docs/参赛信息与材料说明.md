## 一、本材料的作用

本包不是资格类证明文件，而是**结果可核查性材料**：汇总全部产物的哈希、部署自检的真实输出，以及支撑正文每个数字的原始测量记录。

目的是让评审不必"相信结论"，而可以逐项复核——包括那些**对我们不利的结果**（负结果同样在原始记录里，未做删改）。

## 三、三步复现（在 K1 上约 3 分钟）

```bash
tar xzf k1-qwen35-opt.tar.gz && cd k1-qwen35-opt
export CIE_HOME=$PWD
ln -s ~/cie/models models        # 或把 GGUF 放进 models/
bash scripts/deploy.sh check     # 环境与依赖
bash scripts/deploy.sh models    # 模型体积与 sha256 校验
bash scripts/deploy.sh smoke     # 端到端出字（2B）
```

**预期输出**：`结果: 通过 11 项，失败 0 项`（`check`）；`smoke` 末尾打印生成速度与首字延迟。

本包 `03_部署自检记录.txt` 是在 K1 上对**交付包本体**执行上述命令的真实输出。

## 五、数据真实性声明

1. 全部性能数字来自 K1 实机测量，原始输出按时间戳归档，未做人工修正；同一指标的多次独立测量若存在偏差，表格中按原始值并列呈现。
2. 文中标注为"负结果"的实验（KV 量化、前缀复用、slot 持久化、投机解码、检查点细粒度等）均为真实执行后的结论，失败记录一并归档。
3. 被后续实验推翻的早期结论，在文档中以"修正"形式显式标注，未删除原表述（见技术文档 §12 第 9 条）。
4. 与正文冲突的原始记录（如 `cmp_tcm.txt`）不删除、不改写，在 §9.5.1 中说明判定依据。
